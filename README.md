# VD Subside - Plateforme de Subsides d'Assurance Maladie

🎯 **Site web ultra-optimisé SEO pour les subsides d'assurance maladie dans le canton de Vaud**

## 🚀 Fonctionnalités

- ✅ **Calculateur de subside instantané** avec formulaire multi-étapes
- ✅ **SEO ultra-optimisé** (Next.js 15, SSR, metadata dynamiques)
- ✅ **Mobile-first design** responsive sur tous les appareils
- ✅ **Performance maximale** (Core Web Vitals optimisés)
- ✅ **Schema.org markup** pour rich snippets Google
- ✅ **CTA partout** pour maximiser les conversions
- ✅ **Pages par ville** du canton de Vaud
- ✅ **FAQ avec accordéon** et markup structuré

## 🛠️ Stack Technique

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Déploiement**: Vercel (optimisé)

## 📦 Installation

```bash
# Installer les dépendances
npm install

# Lancer en développement
npm run dev

# Build de production
npm run build

# Démarrer en production
npm start
```

## 🌐 Déploiement sur Vercel

1. Connectez votre repo GitHub
2. Importez le projet sur Vercel
3. Configurez le domaine vd-subside.ch
4. Déployez !
